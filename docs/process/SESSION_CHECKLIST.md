# Session Checklist

## Start of Session
- [ ] Read ROADMAP.md and AGENTS.md.
- [ ] Pick exactly one next task (or a tightly scoped pair).
- [ ] Restate acceptance criteria before implementation.

## During Session
- [ ] Keep edits atomic and task-focused.
- [ ] Capture verification evidence while working.
- [ ] Document decisions that affect future tasks.

## End of Session
- [ ] Update ROADMAP.md task status.
- [ ] Update decision log if a new decision was made.
- [ ] Commit completed task(s) with task ID in message.
- [ ] Leave clear next-step note in ROADMAP.md or related doc.
